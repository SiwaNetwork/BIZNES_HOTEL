```
Уважаемые коллеги,

Для подготовки к монтажу системы точного времени нам требуется следующая информация:

1. СХЕМА СЕТЕВОЙ ИНФРАСТРУКТУРЫ:
   - Топология локальной сети (VLAN, подсети)
   - Модель и расположение коммутаторов
   - Текущее распределение IP-адресов в серверной подсети
   - Наличие сегментации сети (гостевая/корпоративная сеть)

2. ИНФРАСТРУКТУРА СЕРВЕРНОЙ:
   - Тип 19" стойки (открытая/закрытая, глубина)
   - Доступность свободного 1U места
   - Альтернативные варианты размещения (настенный монтаж)
   - Температурный режим в помещении

3. ЭЛЕКТРОПИТАНИЕ:
   - Доступность розеток 220V 60 Гц рядом с местом размещения оборудования
   - Наличие заземления (проверка контура заземления)
   - Стабильность электроснабжения (наличие ИБП/генератора)
   - Максимальная мощность потребления в стойке
   - ⚠️ Учитывать, что на Кубе электросеть работает на частоте 60 Гц

4. ДОСТУП НА КРЫШУ:
   - Координаты здания (для расчёта видимости спутников)
   - Высота здания и наличие препятствий (антенны, вышки)
   - Тип кровли (плоская/скатная)
   - Доступ к парапету или мачте для крепления антенны
   - Наличие существующих GNSS-антенн других систем

5. МАРШРУТ КАБЕЛЯ:
   - Расстояние от крыши до серверной (метры)
   - Наличие кабельных трасс/каналов
   - Возможность прокладки коаксиального кабеля RG-6/LMR-400
   - Место для установки грозозащиты (SPD) на крыше рядом с антенной

6. ПРОЦЕДУРЫ РАБОТЫ:
   - Процедура получения доступа к серверной и крыше
   - Время работы технического персонала


Срок предоставления информации: не позднее 10.11.2025
```

```
Техническое задание для настройки сети:

1. ПРЕДЛАГАЕМЫЕ IP-АДРЕСА:

   - DNS-сервер: [текущий DNS отеля]

   - NTP (123/UDP) - входящий/исходящий
   - PTP (319,320/UDP) - входящий/исходящий
   - SSH (22/TCP) - входящий из VPN подсети
   - HTTPS (443/TCP) - входящий для веб-интерфейса
  - Syslog предпочтительно по TLS (6514/TCP), при отсутствии поддержки — 514/UDP

   - Включить IGMP snooping для multicast трафика
   - Настроить QoS для приоритизации PTP трафика

Прошу согласовать данные параметры или предложить альтернативы. Port forwarding использовать только как крайнюю меру; по умолчанию — доступ через OpenVPN.
```

## 📡 Детальные запросы к оператору связи (ETECSA)

### 1. Каналы связи между объектами (ОПЦИОНАЛЬНО)

**⚠️ ВАЖНО:** Выделенные каналы между офисом и отелями не являются обязательными. Каждый Quantum Grand Master может быть подключен к обычному интернету отеля для удалённого мониторинга через OpenVPN к SHIWA NETWORK MONITORING.

**Технические требования к каналам (по возможности):**

```
ВАРИАНТ 1: ВЫДЕЛЕННЫЕ КАНАЛЫ (рекомендуемый, но не обязательный):

1. МЕЖДУ ОФИСОМ ГАВАНЫ И КАЖДЫМ ОТЕЛЕМ:
   - Тип канала: Выделенный Ethernet (не VPN через интернет)
   - Пропускная способность: ≥10 Мбит/с гарантированная
   - Задержка (latency): ≤50 мс
   - Тип подключения: Fiber optic или высококачественный медный кабель

2. ПАРАМЕТРЫ МОНИТОРИНГА:
   - ICMP ping доступность
   - Мониторинг потери пакетов (packet loss ≤0.1%)
   - Мониторинг jitter (вариации задержки)

3. РЕЗЕРВИРОВАНИЕ:
   - Наличие резервного канала
   - Время переключения на резерв ≤30 секунд
   - Автоматический фейловер

Срок организации каналов (при наличии): до 15.11.2025

ВАРИАНТ 2: ИНТЕРНЕТ-ПОДКЛЮЧЕНИЕ (альтернатива):

1. ПОДКЛЮЧЕНИЕ ЧЕРЕЗ ИНТЕРНЕТ ОТЕЛЯ:
   - Каждый Quantum Grand Master подключается к интернету отеля
   - Пропускная способность: ≥5 Мбит/с (достаточно для мониторинга)
   - OpenVPN туннель к SHIWA NETWORK MONITORING
   - Статический IP или DynDNS для доступа

2. ПРЕИМУЩЕСТВА:
   - Не требуется выделенный канал от оператора
   - Используется существующая инфраструктура отеля
   - Более простая и быстрая реализация
   - Меньшие эксплуатационные затраты

3. ТРЕБОВАНИЯ К БЕЗОПАСНОСТИ:
  - OpenVPN с сертификатами для шифрования (TLS 1.3, tls-auth/tls-crypt)
  - Ротация сертификатов не реже 1 раза в 12 месяцев, поддержка CRL/OCSP
   - Firewall правила для доступа только к системе мониторинга
   - Регулярная смена ключей доступа
```

### 4. Подключение к офису в РФ

**Требования к VPN-соединению:**

1. **Тип соединения:** Site-to-Site VPN (OpenVPN)
2. **Шифрование:** AES-256-GCM или аналогичное
3. **Аутентификация:** Сертификаты или Pre-Shared Key
4. **Пропускная способность:** ≥50 Мбит/с
5. **Доступность:** ≥99.5%
6. **Мониторинг:** Постоянный контроль качества соединения

**Настройка на стороне оператора:**
