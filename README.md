## 🎯 Краткое описание проекта

**Цель:** Обеспечить высокоточную синхронизацию времени в трех отелях Кубы с централизованным мониторингом из Гаваны и последующим месячным тестированием стабильности.

**Объекты:**
- Meliá Internacional (Варадеро)
- Meliá Cohiba (Гавана)
- Hotel Nacional (Гавана)
- Центральный офис мониторинга (Гавана) - **предоставляется ETECSA**
  * Серверная стойка 20U с SHIWA NETWORK MONITORING
  * Сервер времени (Quantum Grand Master 4)
  * GNSS-антенна на крыше офиса

**Технологии:**
- Quantum Grand Mini PTP (4 шт.) - источники точного времени (3 в отелях + 1 в центральном офисе)
- GNSS-антенны с GPS/ГЛОНАСС (4 шт.)
- Серверная стойка 20U с серверами мониторинга в центральном офисе
- Протоколы NTP и PTP (IEEE 1588)
- Система мониторинга SHIWA NETWORK MONITORING с публичным IP для удалённого доступа

**⚠️ Важная информация:**
- Все оборудование, кабели, материалы и инфраструктура PKI поставляются компанией **SHIWA NETWORK**.
- Центральный офис мониторинга в Гаване предоставляется оператором связи **ETECSA**.
- Отели обеспечивают только инфраструктуру (доступ, электропитание, сетевые подключения).
- **Критичное требование:** Электропитание 220V 60 Гц с заземлением (кубинский стандарт электросети).

## 📊 Ключевые метрики проекта

| Параметр | Целевое значение | Текущий статус |
|----------|------------------|----------------|
| Точность NTP | ≤ ±50 мс | ⏳ Планируется |
| Точность PTP | ≤ ±100 нс | ⏳ Планируется |
| Доступность системы | ≥99.9% | ⏳ Планируется |
| Количество инцидентов синхронизации | Снижение на ≥80% | ⏳ Планируется |
| Стабильность системы (за месяц) | Доступность ≥99.5% | ⏳ Планируется |
