# Модуль спутниковой связи сверхкомпактный — ТЕНШ.464512.001

Справка о возможной реализации модуля спутниковой связи для малоразмерного биогибридного
летательного аппарата (голубя) с бюджетом массы полезной нагрузки 40–60 г.
Стадия — технический проект (проработка). Документы оформлены по ЕСКД.

## Комплект документов (`docs/`)

| Обозначение | Документ | Формат |
|---|---|---|
| ТЕНШ.464512.001 ПЗ | Справка о возможной реализации. Пояснительная записка | А4, 19 л. |
| ТЕНШ.464512.001 Э1 | Схема электрическая структурная | А3 |
| ТЕНШ.464512.001 ГЧ | Габаритный чертёж (модуль, антенна, 3D-вид) | А3 |
| ТЕНШ.758726.001 | Плата печатная. Чертёж | А3 |

## 3D-модель и макет (`cad/`)

- `module.step`, `antenna.step`, `assembly.step` — 3D-модели (STEP AP214, с цветами);
- `mockup_module.stl`, `mockup_antenna.stl` — печать массогабаритного макета;
- `renders/*.png` — изометрические виды.

## Ключевые цифры (оценка)

| Параметр | Значение |
|---|---|
| Модуль без корпуса | 32 × 22 × 2,5 мм, ≈ 4 г |
| Диапазон | L-диапазон ПСС, ПД 1626,5–1660,5 МГц / ПР 1525–1559 МГц, через КА на ГСО |
| Мощность ПД | 0,1–1 Вт; потребление при ПД 1,5–2,6 Вт (импульсно), приём ≤ 85 мВт, сон ≤ 0,2 мВт |
| Скорость | ПД 100–2400 бит/с, ПР 300–4800 бит/с (зависит от КА) |
| Антенна | керамическая 25 × 25 × 4 мм (10,5 г) или спиральная ⌀12 × 30 мм (5–7 г) |
| Комплект связи | 15,6 г (базовый), ≈ 11 г (облегчённый) |

## Сборка

```bash
pip install reportlab cadquery vtk pillow numpy
xvfb-run -a python3 src/build.py      # всё, включая 3D и рендеры
python3 src/build.py --no-3d          # только PDF-документы
python3 src/calc.py                   # расчёты радиолинии и энергетики
```

Обозначения: код организации ТЕНШ (ГОСТ 2.201). Все значения — расчётные и подлежат
подтверждению макетированием.
