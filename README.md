# Модуль спутниковой связи сверхкомпактный — ТЕНШ.464512.001

Справка о возможной реализации модуля спутниковой связи для малоразмерного биогибридного
летательного аппарата (голубя) с бюджетом массы полезной нагрузки 40–60 г.
Стадия — технический проект (проработка). Документы оформлены по ЕСКД.

## Проекты плат KiCad (`kicad/`)

| Каталог | Плата | Слои | DRC |
|---|---|---|---|
| `TENSH.464512.001` | модуль L-диапазона 32 × 22 мм | 4 | без нарушений |
| `TENSH.464512.002` | носитель модема Iridium 32 × 45 мм | 2 | без нарушений |

В каждом каталоге — схема (`.kicad_sch`), плата (`.kicad_pcb`), библиотеки проекта, отчёт DRC и
производственные файлы `fab/`: Gerber, сверловка, перечень (BOM) и координаты для монтажа (архив `*_gerber.zip`).
Схема и плата строятся из одного списка соединений (`src/hw/*.py`), из него же — Э3, ПЭ3 и спецификация.

## 3D-модель и макет (`cad/`)

- `module.step`, `antenna.step`, `assembly.step` — 3D-модели модуля L-диапазона (STEP AP214, с цветами);
- `module_iridium.step` — 3D-модель варианта Iridium;
- `mockup_module.stl`, `mockup_antenna.stl` — печать массогабаритного макета;
- `renders/*.png` — изометрические виды.

## Сборка

```bash
apt install poppler-utils xvfb kicad openjdk-17-jre   # + Freerouting 1.9 (FREEROUTING_JAR)
pip install reportlab cadquery vtk pillow numpy fonttools
xvfb-run -a python3 src/build.py      # всё, включая 3D и рендеры
python3 src/build.py --no-3d          # только PDF-документы
python3 src/calc.py                   # расчёты радиолинии и энергетики
python3 src/build_hw.py lband         # проект KiCad модуля: схема, плата, трассировка, DRC, Gerber
python3 src/build_hw.py iridium       # то же для платы-носителя Iridium
python3 src/gen_hw_docs.py lband iridium   # Э3, ПЭ3, спецификации
```

Обозначения: код организации ТЕНШ (ГОСТ 2.201). Все значения — расчётные и подлежат
подтверждению макетированием.
